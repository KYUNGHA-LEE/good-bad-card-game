# 좋은말 나쁜말 카드 게임 (good-bad-card-game)

화면에 나온 말 카드 중에서 좋은말만 골라 클릭하는 실시간 수업용 카드 게임입니다. 언어 습관·인성 교육 수업에서 활용할 수 있습니다.

## 게임 방법

1. 강사가 새 방을 만들고 게임을 시작합니다.
2. 학생은 닉네임을 입력하고 입장해 카드들 중 좋은말을 클릭합니다.
3. 좋은말을 고르면 +1점, 나쁜말을 고르면 -1점입니다.
4. 강사는 점수판을 실시간으로 확인하며 카드 바꾸기, 게임 초기화를 할 수 있습니다.

## 기술 구성

- 단일 `index.html` — HTML/CSS/JS (프레임워크 없음)
- Firebase Realtime Database — 강사·학생 화면 실시간 동기화
- 별도 서버 없이 정적 호스팅(Vercel, Firebase Hosting 등)으로 바로 배포할 수 있습니다.
